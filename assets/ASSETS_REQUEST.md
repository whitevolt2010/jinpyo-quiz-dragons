# 어휘 용사: 퀴즈 앤 드래곤 — 그림·소리 제작 요청서

7살·5살 아이용 웹 퀴즈 게임. 1992년 캡콤 오락실 게임 "Quiz & Dragons" 느낌(판타지 RPG + 말판 + 4지선다 퀴즈).
**그림체: 90년대 캡콤 오락실 16비트 픽셀아트 느낌의 밝고 귀여운 판타지.** 무섭지 않게(5살도 보는 게임), 선명한 색, 굵은 외곽선.
그림 안에 글자(특히 한글·영어)는 절대 넣지 말 것 — 글자는 게임이 따로 그린다.

## 결과물 위치와 형식 (파일 이름 그대로 지켜 주세요 — 게임 코드가 이 이름으로 불러옵니다)
- 그림: `assets/img/*.webp` (Pillow로 webp 저장, quality 85 정도)
- 효과음: `assets/sfx/*.mp3`, 배경음악: `assets/bgm/*.mp3` (ffmpeg 있음)
- 전체 용량 합계 15MB 이하 목표.
- 다 끝나면 `assets/manifest.json`에 파일 목록·크기(px)·용량을 적고, `assets/contact_sheet.png`(모든 그림 썸네일 한 장)를 만들어 주세요.

## 투명 배경이 필요한 그림 (캐릭터·몬스터·아이템)
이미지 생성은 가짜 체크무늬 배경을 그려 넣는 경우가 많습니다. 반드시 **단색 배경(예: 순수 마젠타 #FF00FF 또는 순수 초록)으로 생성한 뒤 파이썬으로 배경을 지워 진짜 알파 채널**을 만들고,
가장자리 색 번짐(마젠타 테두리)을 정리하세요. 저장 후 네 모서리 픽셀 alpha==0 인지, 체크무늬가 없는지 직접 확인하세요.
캐릭터·몬스터는 몸 전체가 보이게, 여백 조금, 정사각형 512×512.

## 효과음 (mp3, 짧고 또렷하게, 90년대 오락실 칩튠 느낌, 음량 고르게 −3dB 피크로 정규화)
coin(동전 넣는 소리) / start(게임 시작 징글 1.5초) / select(메뉴 결정) / cursor(커서 이동, 아주 짧게) /
dice_roll(주사위 굴러가는 다다닥, 1.2초) / dice_stop(딱!) / step(말판 한 칸 이동 톡) /
correct(정답 딩동댕 밝게) / wrong(오답 뿌우~ 우스꽝스럽게, 무섭지 않게) /
attack(칼 휘두르는 슉) / hit(몬스터 맞는 퍽) / enemy_attack(몬스터가 때리는 쿵) / gem(보석 켜지는 반짝) /
monster_down(몬스터 쓰러지는 뿅~) / heal(회복 띠링링) / treasure(보물 획득 징글) / magic(요정 마법 반짝반짝) /
boss_appear(보스 등장 경고음 2초) / tick(시간 째깍) / timer_warn(시간 거의 끝 삐삐) / levelup(레벨업 징글) /
stage_clear(스테이지 클리어 팡파르 3초) / game_over(게임오버 짧은 슬픈 멜로디, 귀엽게) / continue(컨티뉴 카운트 띵)

## 배경음악 (mp3, 끊김 없이 이어 반복되는 루프, 칩튠 4채널 느낌, 각 40~70초)
title(설레는 모험 시작) / map(즐겁게 걷는 말판 음악) / battle(경쾌한 퀴즈 전투) / boss(긴장감 있지만 신나는 보스전) /
inn(따뜻한 여관) / ending(축하 엔딩, 루프 아니어도 됨)
음악은 파이썬으로 직접 합성해도 됩니다(사각파·삼각파·노이즈 드럼). 필요한 파이썬 패키지는 이 폴더 안 가상환경(.venv)에만 설치하세요.
