## 제작 방법과 확인 결과

그림은 내장 이미지 생성 도구를 각 자산마다 호출해 만들었습니다. 밝은 90년대 16비트 판타지 픽셀아트, 굵은 외곽선, 어린이에게 무섭지 않은 표현을 사용했습니다. 별도 API/CLI 이미지 생성은 사용하지 않았습니다.

투명 그림에는 단색 마젠타 배경을 요청하고 Python으로 색상을 제거했습니다. 도구가 이미 알파 채널을 준 결과는 마젠타 바탕에 합성한 뒤 같은 제거 과정을 적용했습니다. 외곽의 마젠타 번짐을 정리하고, 내용물을 정사각형 안에 여백을 두고 배치했습니다. 픽셀 느낌을 유지하는 최근접 보간과 Pillow WebP quality 85를 사용했습니다.

- 투명 그림 **36/36장**: 저장된 WebP를 다시 열어 네 모서리 알파가 모두 0인지 확인했습니다. 빈 그림이 아닌지, 외곽 여백이 있는지, 강한 마젠타 키 색이 남지 않았는지도 검사했습니다.
- 배경 **18/18장**: 1280×720, 완전 불투명 확인. 다른 그림도 요청한 128·256·512·768 크기와 모두 일치합니다.
- 최종 썸네일 전체를 직접 확인했습니다. 몸통·무기 잘림, 가짜 체크무늬, 눈에 띄는 마젠타 테두리가 보이지 않습니다. 적은 왼쪽을 향하고, 지도 가운데에는 길이 없으며, 전투 배경 아래에는 설 자리가 있습니다. 타이틀 위쪽에는 로고 공간이 있습니다.
- `gem_off.webp`는 생성된 `gem_on.webp`를 회색으로 낮춰 **동일한 보석 형태와 알파 실루엣**을 유지했습니다. 별도로 생성했던 회색 보석 원본은 최종 파일에 사용하지 않았습니다.

음악과 효과음은 기존 음원을 가져오지 않고 Python으로 직접 합성했습니다. 사각파 계열 멜로디·아르페지오, 삼각파 베이스, 노이즈 드럼으로 4채널 칩튠 느낌을 냈습니다. ffmpeg로 44.1kHz 모노, 128kbps MP3를 만들고, 다시 디코딩한 신호를 기준으로 피크를 보정했습니다.

- 소리 **30/30개** 디코딩 성공. 최종 피크 범위 **−3.059~−2.965dBFS**로, 목표 −3dB에 근접합니다. 클리핑이 없습니다.
- 시작 1.5초, 주사위 1.2초, 보스 등장 2초, 스테이지 클리어 3초를 확인했습니다.
- 배경음악: title 64초, map 약 56.47초, battle 48초, boss 약 53.33초, inn 60초, ending 60초.
- 엔딩을 제외한 5곡은 반복용입니다. MP3 gapless 메타데이터를 기록했고, 디코딩된 샘플 수와 루프 경계 진폭 차이를 검사했습니다. 경계 차이는 모두 0.0064 미만입니다. 엔딩은 마지막에 음량이 내려가며 마칩니다.

## 사용 시 주의할 점

- MP3 반복은 플레이어가 gapless 메타데이터를 반영해야 합니다. 엄밀한 반복에는 Web Audio로 한 번 디코딩한 뒤 버퍼를 반복하는 방식이 적합합니다. 루프 시작은 샘플 0, 끝은 manifest의 `decoded_samples`(끝 샘플 제외)입니다. 브라우저별 재생 동작은 게임 통합 시 확인해야 합니다.
- 피크 음량을 맞춰도 음색에 따른 체감 음량은 다를 수 있습니다. 배경음악과 효과음의 상대 음량은 게임에서 조절할 수 있습니다.
- 이미지 생성 결과의 세부 픽셀 크기와 인체 비율에는 약간의 차이가 있습니다. 전체 화풍과 캔버스 여백을 맞췄지만 단일 픽셀 격자로 수작업 제작한 스프라이트는 아닙니다.
- 가상환경은 `.venv`입니다. 패키지 다운로드가 네트워크 제한으로 실패하여, 새 패키지를 전역 설치하지 않고 이미 설치된 Python 3.12의 Pillow 12.2.0·NumPy 1.26.4를 가상환경에서 참조했습니다.
- 재검사는 프로젝트 루트에서 `.venv/bin/python assets/tools/finalize.py`로 실행할 수 있습니다. 음원 재생성은 `build_audio.py`, 그림 후처리는 `build_images.py`입니다. 그림 재처리는 `generation_sources.json`에 기록된 이 컴퓨터의 생성 원본이나 `/private/tmp/jinpyo-assets-source/`의 복사본이 필요합니다. 최종 게임 사용에는 `img/`, `sfx/`, `bgm/`의 완성 파일만 있으면 됩니다.
