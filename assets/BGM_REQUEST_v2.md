# 배경음악 다시 만들기 요청 (v2)

부모님 의견: "배경음악이 너무 산만하다. 아이들 정서에 안 좋다. 교육 게임이다."
지금 `assets/bgm/*.mp3`(이전 판은 `assets/bgm_old/`에 백업)는 빠른 칩튠이라 정신없음 → **차분하고 따뜻한 음악**으로 6곡 모두 다시 만들어 주세요.

## 방향
- 느긋한 박자: 70~90 BPM (엔딩만 100 정도까지)
- 부드러운 음색: 오르골(music box), 마림바/실로폰, 부드러운 전자피아노, 따뜻한 패드(사인파·삼각파 위주). **사각파·톱니파의 날카로운 칩튠 소리, 노이즈 드럼, 빠른 아르페지오 금지.**
  타악기가 필요하면 아주 작고 부드러운 소리(셰이커·우드블록 정도)만.
- 화음은 단순하고 밝게(장조, 1-4-5-6 위주), 멜로디는 천천히, 같은 높은음 반복 피하기.
- 음량 변화가 크지 않게, 공부에 집중을 방해하지 않는 "배경" 느낌. 고음을 너무 쓰지 말 것(귀가 피곤하지 않게, 대략 2.5kHz 이상은 부드럽게 깎기).
- 각 곡은 끊김 없이 반복되는 루프(엔딩 제외), 60~90초. 첫 소리와 끝 소리가 자연스럽게 이어지게.
- 피크 −6dBFS 정도로 정규화(효과음보다 조용하게), 44.1kHz, mp3.

## 곡별 느낌 (파일 이름 그대로)
- title.mp3 — 동화책 첫 장을 여는 듯한 설렘, 오르골
- map.mp3 — 숲길을 천천히 산책하는 느낌, 마림바 + 부드러운 베이스
- battle.mp3 — 퀴즈를 생각하며 푸는 시간. 잔잔하지만 살짝 궁금한 느낌. 긴장감·빠른 박자 금지
- boss.mp3 — 조금 더 웅장하지만 무섭지 않게, 느린 현악 패드 + 낮은 음, 90 BPM 이하
- inn.mp3 — 따뜻한 벽난로 앞, 아주 포근하게
- ending.mp3 — 잘 해냈다는 따뜻한 축하, 부드러운 팡파르(날카롭지 않게)
